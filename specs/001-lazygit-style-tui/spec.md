# Feature Specification: LazyGit 风格 TUI 界面

**Feature Branch**: `001-lazygit-style-tui`
**Created**: 2025-12-07
**Status**: Draft
**Input**: 基于 LAZYGIT_STYLE_ROADMAP.md 实现完整的终端用户界面

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 三面板浏览与导航 (Priority: P1)

用户启动应用后，看到一个专业的三面板界面：左侧显示源目录的文件树，中间显示可用的批量操作列表，右侧显示选中项的预览信息。用户可以通过键盘在三个面板之间切换焦点，并使用方向键或 Vim 风格快捷键进行导航。

**Why this priority**: 这是整个 TUI 的基础框架，所有其他功能都依赖于此布局系统。没有三面板布局，用户无法进行任何操作。

**Independent Test**: 可以独立测试三面板是否正确渲染、焦点切换是否正常工作、导航键是否响应。即使没有实际文件操作功能，用户也能体验到专业的界面布局。

**Acceptance Scenarios**:

1. **Given** 用户启动应用并指定源目录, **When** 界面加载完成, **Then** 用户看到三面板布局：左侧目录树、中间操作清单、右侧预览面板
2. **Given** 焦点在左侧目录树面板, **When** 用户按 Tab 键, **Then** 焦点移动到中间操作清单面板，边框颜色变化指示焦点位置
3. **Given** 用户在目录树中, **When** 用户按 ↓ 或 j 键, **Then** 光标移动到下一个文件/文件夹项
4. **Given** 用户选中一个文件夹, **When** 用户按 Enter 或 l 键, **Then** 文件夹展开显示其内容
5. **Given** 用户按 q 键, **When** 界面显示确认对话框, **Then** 用户确认后应用安全退出

---

### User Story 2 - 批量操作选择与预览 (Priority: P1)

用户在中间面板看到 6 个预定义的批量操作（删除空文件夹、移动中文字幕视频、移动无码视频、重命名大写、删除前缀、删除广告）。每个操作显示复选框状态和影响范围统计。用户可以切换操作的启用/禁用状态，并在右侧预览面板查看将受影响的文件列表。

**Why this priority**: 批量操作是工具的核心价值，用户需要清楚地了解每个操作会影响哪些文件，以避免误操作。

**Independent Test**: 可以测试操作列表显示、复选框切换、影响统计计算是否正确。用户可以在不执行操作的情况下预览变化。

**Acceptance Scenarios**:

1. **Given** 目录扫描完成, **When** 用户查看操作清单, **Then** 每个操作显示：名称、描述、影响文件数量
2. **Given** 焦点在操作清单, **When** 用户按 Space 键, **Then** 当前操作的启用状态切换，图标从 [✓] 变为 [ ] 或反之
3. **Given** 用户选中"移动中文字幕视频"操作, **When** 右侧预览面板更新, **Then** 显示所有匹配 -C、-ch 后缀的文件列表
4. **Given** 用户按 a 键, **When** 操作清单响应, **Then** 所有操作切换为全选或全不选状态

---

### User Story 3 - 手动移动单个文件 (Priority: P1)

用户在目录树中选中任意文件或文件夹，按 m 键打开移动对话框。对话框显示快速目标选择（数字键 1-9 直达常用目录）和路径输入框（支持 Tab 补全）。用户选择目标后，系统显示移动预览并检测冲突，确认后执行移动。

**Why this priority**: 手动移动功能补充了批量操作，让用户可以灵活处理不符合预设规则的文件，提升工具的实用性。

**Independent Test**: 可以测试移动对话框显示、目标选择、路径补全、冲突检测、移动执行是否正确工作。

**Acceptance Scenarios**:

1. **Given** 用户在目录树选中一个文件, **When** 用户按 m 键, **Then** 弹出移动对话框，显示源文件信息和目标选择列表
2. **Given** 移动对话框打开, **When** 用户按数字键 1, **Then** 文件直接移动到 CHINESE/ 目录
3. **Given** 移动对话框打开, **When** 用户输入路径并按 Tab, **Then** 系统提供路径自动补全建议
4. **Given** 目标路径已存在同名文件, **When** 用户确认移动, **Then** 系统显示冲突警告并询问是否覆盖
5. **Given** 用户按 v 键进入多选模式, **When** 用户选择多个文件后按 m, **Then** 移动对话框显示"已选择 N 个文件"并支持批量移动

---

### User Story 4 - 执行操作与进度显示 (Priority: P2)

用户配置好操作后按 Enter 键开始执行。界面切换到执行模式，显示总体进度条、当前操作进度、实时日志窗口和统计面板。用户可以看到处理速度、剩余时间估算，以及已处理/移动/删除/重命名的文件数量。

**Why this priority**: 执行反馈是用户体验的关键，让用户了解操作进度，减少等待焦虑，及时发现错误。

**Independent Test**: 可以测试执行模式界面、进度条更新、日志输出、统计计算是否正确。

**Acceptance Scenarios**:

1. **Given** 用户选择了操作并按 Enter, **When** 执行开始, **Then** 界面切换到执行模式，显示双进度条（总体 + 当前操作）
2. **Given** 执行过程中, **When** 文件被处理, **Then** 实时日志窗口显示每个操作的结果，颜色编码区分成功/警告/错误
3. **Given** 执行过程中, **When** 用户查看统计面板, **Then** 显示已处理/移动/删除/重命名/跳过/错误的文件数量
4. **Given** 用户按 Ctrl+C, **When** 系统收到中断信号, **Then** 显示确认对话框，用户可选择继续或中止

---

### User Story 5 - 帮助系统与快捷键 (Priority: P3)

用户在任何时候按 F1 或 h 键可以呼出帮助面板，显示当前上下文可用的所有快捷键和操作说明。帮助内容分类清晰，支持滚动查看。

**Why this priority**: 帮助系统提升可学习性，但用户可以通过底部快捷键提示学习基本操作，因此优先级较低。

**Independent Test**: 可以测试帮助面板显示、内容分类、滚动功能是否正常工作。

**Acceptance Scenarios**:

1. **Given** 用户在任意界面, **When** 用户按 F1 或 h 键, **Then** 帮助面板覆盖显示，列出所有快捷键
2. **Given** 帮助面板打开, **When** 用户按 ↓ 键, **Then** 帮助内容向下滚动
3. **Given** 帮助面板打开, **When** 用户按 Esc 或 q, **Then** 帮助面板关闭，返回之前界面

---

### Edge Cases

- 源目录为空或不存在时，显示友好错误提示并允许用户重新选择
- 文件数量超过 10,000 时，显示扫描进度并分批加载
- 终端窗口过小（小于最小尺寸）时，显示提示要求调整窗口
- 文件被其他进程占用时，跳过并记录错误，继续处理其他文件
- 磁盘空间不足时，在执行前检测并警告用户
- 用户权限不足时，显示具体哪些文件无法操作

## Requirements *(mandatory)*

### Functional Requirements

**核心 UI 框架**

- **FR-001**: 系统 MUST 提供三面板布局：左侧目录树（30%）、中间操作清单（40%）、右侧预览（30%）
- **FR-002**: 系统 MUST 支持 Tab 键在三个面板之间循环切换焦点
- **FR-003**: 系统 MUST 通过边框颜色变化指示当前焦点面板
- **FR-004**: 系统 MUST 在顶部显示状态栏（应用标题、当前目录路径）
- **FR-005**: 系统 MUST 在底部显示上下文相关的快捷键提示

**目录树面板**

- **FR-006**: 系统 MUST 异步扫描指定目录，显示文件夹和文件的树形结构
- **FR-007**: 系统 MUST 支持 ↑↓ 或 jk 键上下移动光标
- **FR-008**: 系统 MUST 支持 Enter 或 l 键展开文件夹，Backspace 或 h 键折叠/返回
- **FR-009**: 系统 MUST 显示文件类型图标、大小和待处理状态标记
- **FR-010**: 系统 MUST 支持 / 键触发搜索功能，过滤显示匹配项

**操作清单面板**

- **FR-011**: 系统 MUST 显示 6 个预定义批量操作的复选框列表
- **FR-012**: 系统 MUST 为每个操作显示影响范围统计（文件数量、释放空间）
- **FR-013**: 系统 MUST 支持 Space 键切换操作启用/禁用状态
- **FR-014**: 系统 MUST 支持 a 键全选/全不选操作

**手动移动功能**

- **FR-015**: 系统 MUST 在用户按 m 键时显示移动对话框
- **FR-016**: 系统 MUST 提供数字键 1-9 快速选择常用目标目录
- **FR-017**: 系统 MUST 支持路径输入和 Tab 键自动补全
- **FR-018**: 系统 MUST 在移动前检测目标冲突并提示用户选择：跳过、覆盖或重命名
- **FR-019**: 系统 MUST 支持 v 键进入多选模式，批量选择文件后统一移动

**预览面板**

- **FR-020**: 系统 MUST 显示选中项的详细信息（路径、大小、修改时间）
- **FR-021**: 系统 MUST 预览当前操作将对选中项产生的变化
- **FR-022**: 系统 MUST 用颜色编码区分操作类型：绿色（安全）、黄色（警告）、红色（危险）

**执行引擎**

- **FR-023**: 系统 MUST 在执行时显示总体进度条和当前操作进度条
- **FR-024**: 系统 MUST 显示实时滚动日志窗口，颜色区分日志级别
- **FR-025**: 系统 MUST 显示统计面板：已处理/移动/删除/重命名/跳过/错误数量
- **FR-026**: 系统 MUST 支持 Ctrl+C 中断操作（需要确认）
- **FR-027**: 系统 MUST 计算并显示处理速度和剩余时间估算
- **FR-027a**: 系统 MUST 自动将执行日志保存到 `~/.rust-jav/logs/` 目录，文件名包含时间戳

**交互系统**

- **FR-028**: 系统 MUST 在危险操作前显示确认对话框
- **FR-029**: 系统 MUST 支持 F1/h 键呼出帮助系统
- **FR-030**: 系统 MUST 支持 q 键退出（有未完成操作时需确认）

### Key Entities

- **FileNode**: 表示文件系统中的一个节点（文件或文件夹），包含路径、名称、大小、类型、子节点列表、展开状态、选中状态、待处理操作标记
- **Operation**: 表示一个批量操作，包含操作类型、描述、启用状态、匹配规则、影响文件列表、影响统计
- **MoveTarget**: 表示移动目标，包含目标路径、是否为预设目录、最近使用时间
- **ExecutionProgress**: 表示执行进度，包含总任务数、已完成数、当前任务名、当前文件、开始时间、速度计算
- **LogEntry**: 表示日志条目，包含时间戳、级别、消息、关联文件路径

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可以在 3 秒内完成从启动到开始浏览目录树
- **SC-002**: 用户可以在 5 次按键内完成单个文件的手动移动操作
- **SC-003**: 系统在处理 1000 个文件的目录时，扫描时间不超过 10 秒
- **SC-004**: 90% 的用户可以在不查阅帮助的情况下完成基本操作（导航、选择操作、执行）
- **SC-005**: 执行进度显示的更新频率至少达到每秒 10 次，确保流畅的视觉反馈
- **SC-006**: 错误发生时 100% 记录到日志并在界面显示，无静默失败
- **SC-007**: 用户可以在 2 秒内通过快捷键访问任何主要功能
- **SC-008**: 相比当前 dialoguer 交互，用户完成完整操作流程的时间减少 50%

## Clarifications

- Q: Should execution logs be persisted to file? → A: Auto-save to `~/.rust-jav/logs/` with timestamp
- Q: How should TUI coexist with current dialoguer CLI? → A: Replace entirely - TUI becomes the only interface

## Technical Constraints

- **TC-001**: TUI 将完全替代现有的 dialoguer 交互界面，不保留旧接口
- **TC-002**: 现有的 dialoguer 相关代码将被移除，使用 Ratatui 重新实现所有交互

## Assumptions

- 用户的终端支持 256 色或真彩色显示
- 终端窗口尺寸至少为 80x24 字符
- 用户熟悉基本的终端操作和键盘导航
- 源目录在本地文件系统，不涉及网络存储
- 用户对 Vim 风格快捷键有基本了解（可选，方向键同样可用）
